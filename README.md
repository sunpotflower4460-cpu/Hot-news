# 明るいニュース｜Hot News

世界の中から、**出来事そのものが明るいニュースだけ**を届けるアプリのプロトタイプです。

暗いニュースをやさしい表現へ言い換えるのではなく、希望、喜び、創造、前進、親切、美しさを感じられる実在の出来事を選ぶことを最優先にしています。

## 現在の状態

このリポジトリは、Next.jsの静的出力で作られたUI/UXプロトタイプです。

- 明るいニュース専用の編集基準と掲載ゲート
- 朝・昼・夕・夜で変わる空と配色
- ホーム、カテゴリ、記事詳細、お気に入り、週刊まとめ、寝る前モード
- オンボーディング、設定、通知・プレミアムの表示プレビュー
- 読み込み、空、エラー、404、オフライン状態
- キーボード、スクリーンリーダー、モーション低減、高コントラストへの配慮
- PWA登録、オフラインフォールバック、アプリショートカット
- 架空のモック記事による画面確認

実ニュース取得、データベース、AI審査、通知配信、課金、アカウント同期、iOSラッピングはまだ実装されていません。

> **注意:** `src/mock/articles.ts` の記事・媒体名・URLはUI確認用の架空データです。実在ニュースとして公開・引用しないでください。

## 製品原則

編集上の絶対条件は [`PRODUCT_PRINCIPLES.md`](./PRODUCT_PRINCIPLES.md) にまとめています。

読者向けに表示される記事は、必ず中央の掲載ゲートを通します。実ニュースへ移行した後も、画面や通知から未審査記事を直接参照しないことが前提です。

記事画面は掲載モードも尊重します。

- `normal` / `no_image`: アプリ内本文を表示
- `safe_short`: 安全な短縮版だけを表示
- `source_link_only`: 本文を再掲載せず、出典への案内だけを表示

## セットアップ

Node.js 20を推奨します。

```bash
npm ci
npm run dev
```

開発サーバーは通常 `http://localhost:3000` で起動します。

## 品質確認

```bash
npm run check
```

以下を順番に実行します。

1. Prettier
2. TypeScript
3. ESLint
4. Next.js静的ビルド

個別にも実行できます。

```bash
npm run format:check
npm run typecheck
npm run lint
npm run build
```

## 静的出力の確認

```bash
npm run build
npm start
```

追加パッケージを使わず、`out` ディレクトリをローカル配信します。

## 手動確認項目

- iPhone相当の狭い画面
- ライト・ダーク・朝・昼・夕・夜
- キーボードだけでの移動
- VoiceOverなどによる読み上げ
- OSの「視差効果を減らす」設定
- 高コントラスト設定
- オフラインと接続復帰
- 記事0件、保存0件、通信エラー、404
- `normal`、`safe_short`、`source_link_only`の表示差

## 主な構成

```text
src/app                    画面・ルート
src/components             UI、テーマ、PWA、レイアウト
src/lib/data/selectors.ts  読者向けデータ取得の窓口
src/lib/editorial          明るいニュース掲載基準
src/mock                   架空の画面確認データ
src/types                  記事・審査データ型
public                     PWA・オフライン資産
```
