## Promotional text

## Description

明るいニュースは、出来事そのものが希望、喜び、親切、創造、美しさ、前進を含むニュースだけを選ぶアプリです。

暗いニュースをやさしく言い換えたり、悲しい出来事の最後だけを感動話として届けたりしません。読む前から安心できるよう、明るさ、感情的な負担、出典の信頼性、権利を確認します。

主な特徴

・朝、昼、夕、夜で変わる柔らかな空のデザイン
・今日の明るいニュース
・動物・自然、人のやさしさ、技術、アート・文化から探す
・出典と公開日を確認できる記事画面
・寝る前に読む一件だけのモード
・お気に入りと端末内データ管理

世界に実在する小さな光を、毎日の習慣に。

## Review-note summary

Hot News applies an editorial publication gate before an article can appear. The central event must be positive, dark context must remain low, the source must be traceable, and publication rights must be safe. The app links to the original source and supports normal, safe-short, and source-link-only display modes.
